# Golden Tech

> A subtle gold theme with old fashion styled header fonts for Spicetify.

---

## Install

1. copy the `GoldenTech` folder into your Spicetify Themes folder:
   - **Windows:** `%appdata%\spicetify\Themes\`
   - **Mac/Linux:** `~/.config/spicetify/Themes/`

2. Open terminal and run:
```bash
spicetify config current_theme GoldenTech
spicetify apply
```
